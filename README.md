# Comprehensive Analysis of Modern Ransomware
Semester-long project regarding the usage of Ransomware on modern ransomware.

# Information

All images and reports have been documumented to this GitHub repository. 

# Tools used

The main analysis tools used for this semester long project are as follows:
> Any.run: https://any.run/ - VM specifically used for malware analysis
> Virus Total: https://www.virustotal.com/gui/home/upload - Analyse suspicious files, domains, IPs and URLs to detect malware
> MITRE ATT&CK https://attack.mitre.org/ - Globally-accessible knowledge base of adversary tactics and techniques based on real-world observations
